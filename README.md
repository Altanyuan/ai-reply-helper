# ai-reply-helper

![机器人形象](assets/robot.jpg)

微信 AI 润色助手：在微信输入框写好草稿（不用发），按一个热键，AI 结合最近聊天上下文生成多个润色版本，选一个自动填回输入框。输入框是空的，还能根据聊天上下文直接帮你起草一条回复。

**发送永远手动** —— 程序只把文字填进输入框，发不发、改不改，你来定。

## 版本下载

| 平台 | 仓库 | 说明 |
|---|---|---|
| Windows | [ai-reply-helper-win](https://github.com/Altanyuan/ai-reply-helper-win) | 微信 3.x / 4.x，热键 `Ctrl+Alt+P` |
| macOS | [ai-reply-helper-mac](https://github.com/Altanyuan/ai-reply-helper-mac) | 微信 Mac 版，截图 + 系统 OCR 读上下文 |

两个版本互相独立，按你的电脑系统进对应仓库看使用说明。

## 实际效果（三个真实场景）

- **给领导认错**：测算方案用了去年旧数据被点名，AI 生成 3 个版本，挑个得体又不卑不亢的发出去；
- **安抚暴怒客户**：客户因物流延误扬言投诉 12315，AI 生成 4 个版本，先稳情绪再给承诺；
- **哄对象**：女朋友质问"一晚上消失干什么去了"，AI 给 3 个高情商版本，先共情再解释。

## 隐私与边界

- 只读你自己电脑上、自己本来就有权查看的对话；不 hook、不注入、不碰微信协议；
- API Key 只保存在你自己电脑的 `config.json`（或环境变量），仓库里的配置文件已脱敏；
- 草稿和上下文会发送给你自己配置的大模型服务商（默认 DeepSeek），**涉及敏感信息时请勿使用**。
